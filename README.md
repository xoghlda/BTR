# BTR · 출장 증빙 캡처

자차·기차 출장의 원본 화면과 영수증을 모아 **출장보고서와 A4 증빙서식**을 만드는 Windows 프로그램입니다. 현재 버전은 **v1.3.1**입니다.

## 다운로드

- **[Windows 64비트 ZIP 다운로드](https://github.com/xoghlda/BTR/releases/download/v1.3.1/BTR-v1.3.1-windows-x64.zip)** — 실행 파일, 한글 안내, 개발용 샘플 PDF를 함께 받습니다.
- **[EXE만 다운로드](https://github.com/xoghlda/BTR/releases/download/v1.3.1/BTR-v1.3.1-windows-x64.exe)** — 실행 파일을 바로 받을 때 사용합니다.
- [최신 릴리스와 변경사항](https://github.com/xoghlda/BTR/releases/latest) · [파일 검증용 SHA256SUMS.txt](https://github.com/xoghlda/BTR/releases/download/v1.3.1/SHA256SUMS.txt)

**배포 EXE를 사용하면 Python을 설치할 필요가 없습니다.** 소스 코드는 이 저장소에서, 실행 파일은 GitHub Releases에서 배포합니다.

현재 EXE에는 코드 서명이 없습니다. 조직 PC의 보안 정책이 실행을 제한하면 담당자에게 확인하세요. 소스 확인·실행 절차는 아래 개발용 안내에서 볼 수 있습니다.

## 1. 실행 준비와 빠른 시작

| 항목 | 준비 사항 |
| --- | --- |
| 운영체제 | Windows 64비트용 배포 파일입니다. Windows 10/11 PC를 대상으로 합니다. |
| 자차 자동 조회 | Chrome 또는 Microsoft Edge 설치, 인터넷 연결 |
| 기차 영수증 수집 | Windows 기본 웹브라우저, 코레일 공식 사이트에서 직접 로그인·조회할 수 있는 환경 |
| 계정 | 하이패스·코레일의 개인 영수증을 조회할 때 해당 사이트의 계정·인증이 필요할 수 있습니다. |
| 저장 공간 | 원본 PDF, 페이지별 PNG, HTML 보고서를 보관할 로컬 폴더 |

1. ZIP을 다운로드하고 **압축을 모두 풉니다**.
2. 압축 안의 **BTR.exe**를 더블클릭합니다. EXE만 받았다면 `BTR-v1.3.1-windows-x64.exe`를 실행합니다.
3. 상단에서 **자차 이용** 또는 **기차 이용**을 선택합니다.
4. 출장 정보와 저장 위치를 입력하고 자료를 수집합니다. 자세한 순서는 아래 유형별 안내를 참고하세요.
5. 완료 후 **보고서 열기** 또는 **결과 폴더 열기**에서 원본과 보고서를 확인합니다.

프로그램 창 제목이 `출장 증빙 캡처 v1.3.1`인지 확인하세요. 실행 파일은 다른 폴더로 옮겨 사용할 수 있지만, 이미 생성한 보고서는 원본 첨부파일과 함께 보관해야 합니다.

파일 해시를 확인하려면 다운로드한 폴더에서 다음 명령의 결과를 릴리스의 `SHA256SUMS.txt`와 비교할 수 있습니다.

```powershell
Get-FileHash .\BTR-v1.3.1-windows-x64.zip -Algorithm SHA256
```

### 처음에는 샘플 PDF로 확인하기

ZIP의 `samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf`는 **SYNTHETIC DEVELOPMENT DATA 표시가 있는 개발용 가상자료**입니다. 유효한 영수증이나 정산 증빙으로 사용할 수 없습니다.

1. **기차 이용**을 선택하고 과거 또는 오늘 날짜와 임의의 샘플 출장정보를 입력합니다. 예: 출장기간 `2026-10-20`~`2026-10-21`, 출장지 `서울`, 가는 편 `오송 → 서울`.
2. **수집 시작**을 누릅니다. 코레일 홈페이지가 열리지만 샘플 확인에는 로그인할 필요가 없습니다.
3. **영수증 PDF 가져오기**에서 위 샘플 PDF를 선택합니다.
4. **3페이지가 저장됐는지 확인**하고 **코레일 수집 완료**를 누릅니다.
5. **보고서 열기**에서 원본 PDF 링크와 페이지별 이미지, 기차 정산서를 확인합니다.

샘플 PDF에는 실제 출장·승차 날짜가 없습니다. 보고서에 입력한 날짜는 테스트용 입력값입니다. 사이트에 로그인하지 않고 PDF 수집·보고서 생성을 확인하는 용도로만 사용하세요.

## 2. 출장 정보와 유형 선택

| 유형 | 수집 자료 | 보고서 제목 | A4 증빙서식 |
| --- | --- | --- | --- |
| 자차 이용 | 네이버 지도 경로, 오피넷 일일 유가, 하이패스 통행료 영수증 | 자차 이용 출장보고서 | `car_settlement.html` |
| 기차 이용 | 코레일 영수증 PDF 또는 직접 선택한 영수증·출력 창 | 기차 이용 출장보고서 | `rail_settlement.html` |

두 유형은 **별도 실행·별도 결과 폴더**로 저장됩니다. 작업 도중에는 유형을 바꿀 수 없습니다.

| 입력 위치 | 입력 내용과 의미 |
| --- | --- |
| **기본 정보** | 출장 시작일, 종료일, 출장지, 저장 위치. 날짜는 `YYYY-MM-DD` 형식이며 종료일을 비우면 당일 출장입니다. |
| **공통 출장정보** | 소속·직급·성명·출장 목적. 보고서와 정산서에 사용됩니다. |
| 자차 기본 정보 | 출발지·출장지, 유종, 자동 조회용 Chrome/Edge, 수집할 사이트 |
| **철도 구간 · 코레일** | 가는 편 출발역·도착역과 선택 사항인 귀환 출발역·도착역 |

예를 들어 실제 왕복 구간이 **오송 → 서울 / 용산 → 오송**이라면 귀환 출발역에 `용산`, 귀환 도착역에 `오송`을 입력하세요. 귀환역을 비우면 가는 편의 역순을 요청 경로로 표시합니다. 이 입력값 자체가 실제 승차 사실을 증명하는 것은 아닙니다.

## 3. 자차 이용

1. **자차 이용**을 선택합니다.
2. 출장기간·출발지·출장지·유종·저장 위치와 공통 출장정보를 입력합니다.
3. **캡처 대상**에서 필요한 네이버 지도·오피넷·하이패스 항목을 선택합니다.
4. **캡처 시작**을 누릅니다. 프로그램이 선택한 Chrome 또는 Edge를 열어 사이트별 조회를 준비합니다.
5. 네이버 지도와 오피넷은 조건을 확인할 수 있으면 자동으로 저장합니다. 장소 후보나 날짜·유종 확인이 필요하면 화면 준비 대기로 전환됩니다.
6. 직접 준비가 필요한 화면은 브라우저에서 조회를 마치고, 프로그램의 **창 목록 새로고침 → 저장할 창 선택 → 현재 화면 저장** 순서로 저장합니다.
7. 하이패스는 직접 로그인·인증한 뒤 출장일·카드·거래 내역과 영수증을 확인합니다. PDF로 출력된다면 **영수증 PDF 가져오기**, 외부 출력 창이라면 **일반 브라우저·출력창 저장**을 사용합니다.
8. 처리가 끝나면 **보고서 열기**에서 자료와 누락 여부를 확인합니다.

하이패스 로그인 정보 저장은 선택 사항입니다. 사용하려면 아이디와 비밀번호를 입력한 뒤 **이 PC에 로그인 정보 저장**을 먼저 누르세요. 저장하지 않아도 열린 브라우저에서 직접 로그인할 수 있습니다. 보안 입력·추가 인증·보안프로그램 확인은 사이트의 정상 절차로 직접 진행합니다.

자차 자동화 브라우저에서 하이패스 로그인이 어려우면 평소 사용하는 브라우저에서 로그인하고 **일반 브라우저·출력창 저장**으로 영수증을 추가할 수 있습니다.

지도는 **조회 시점의 참고 경로**입니다. 과거 출장일의 실제 운행 경로나 당시 교통상황을 재현하지 않습니다. 거리·유가·통행료는 원본에서 확인하며 프로그램이 교통비를 임의로 계산하지 않습니다.

## 4. 기차 이용 · 코레일

v1.3.1 기차 모드는 **평소 사용하는 일반 브라우저에서 직접 로그인하고 영수증을 모으는 방식**입니다. 기차 수집에는 Playwright 자동화 브라우저를 실행하지 않습니다.

1. **기차 이용**을 선택합니다.
2. 공통 출장정보와 **철도 구간 · 코레일** 탭의 왕복 역을 입력합니다.
3. **수집 시작**을 누릅니다. Windows 기본 브라우저로 [코레일 공식 홈페이지](https://www.korail.com/ticket)를 엽니다. 기본 정보의 Chrome/Edge 선택은 자차 자동 조회용입니다.
4. 일반 브라우저에서 코레일에 **직접 로그인·추가 인증**하고 마이페이지의 공식 이용내역·영수증 메뉴를 엽니다.
5. 조회 기준이 구입일인지 승차일인지 확인하고, 해당 출장의 **실제 승차일·출발역·도착역**에 맞는 영수증을 준비합니다. 예매일과 출장일은 다를 수 있습니다.
6. 다음 중 한 방법으로 자료를 추가합니다.

   | 추가 방법 | 사용 순서 |
   | --- | --- |
   | **영수증 PDF 가져오기** | 공식 출력·인쇄 기능에서 PDF로 저장 → 프로그램에서 파일 선택. 원본 PDF와 모든 페이지를 보관합니다. |
   | **일반 브라우저·출력창 저장** | 실제 영수증이 보이는 브라우저·PDF 뷰어·출력 앱 창을 선택해 화면을 저장합니다. 아래의 4초 캡처 순서를 따르세요. |

7. 왕복 등 필요한 영수증을 계속 추가합니다. **한 장을 저장해도 수집 대기를 유지합니다.**
8. 모두 추가한 뒤 반드시 **코레일 수집 완료**를 누릅니다.
9. `travel_report.html`의 정산서 링크 또는 `rail_settlement.html`을 열어 확인합니다. 영수증 이미지는 한 쪽에 최대 두 개씩 배치되며 추가 자료는 다음 쪽으로 이어집니다.

기본 브라우저가 열리지 않으면 **기본 브라우저로 코레일 열기**를 누르거나 공식 주소에 직접 접속하세요. 일반 브라우저에서 다운로드한 PDF는 **영수증 PDF 가져오기**로 직접 추가합니다.

**코레일의 보안·접근 차단이나 실제 계정의 로그인 성공이 해결됐다고 검증된 것은 아닙니다.** 일반 브라우저에서도 문제가 계속되면 코레일의 공식 안내를 확인하세요. 프로그램은 인증을 대신하거나 접근 제한을 해제하지 않습니다.

PDF·외부 창에서 가져온 승차일·역·금액은 원본과 대조하세요. 정산서의 **사용자 입력** 표시는 요청한 출장기간·역 정보이며, 영수증에서 확인된 사실과 구분됩니다. PDF의 각 페이지에 임의로 가는 편·오는 편을 배정하지 않습니다.

## 5. PDF와 화면 캡처의 차이

| 방법 | 저장되는 범위 | 주소 표시줄 | 적합한 경우 |
| --- | --- | --- | --- |
| **영수증 PDF 가져오기** | 원본 PDF 파일 + **모든 페이지**의 PNG | 포함되지 않음 | PDF 출력 영수증, 길거나 여러 페이지인 자료 |
| **일반 브라우저·출력창 저장** | 선택한 창에서 **현재 보이는 영역** | 브라우저 창이면 포함 | 일반 브라우저, PDF 뷰어, 별도 출력 앱 |
| **현재 화면 저장** | 자차 자동화 브라우저의 웹페이지 내용. 사이트에 따라 전체 페이지 또는 현재 영역 | 포함되지 않음 | 프로그램이 연 네이버·오피넷·하이패스 창 |

### 일반 브라우저·출력 창 저장 순서

1. 실제 영수증을 브라우저나 출력 앱에 표시합니다. 로그인 화면·조회 목록을 선택하지 마세요.
2. 프로그램에서 **일반 브라우저·출력창 저장**을 누릅니다.
3. **PDF 뷰어·별도 출력창 포함**을 확인하고 **창 목록 새로고침**을 누릅니다.
4. 저장할 창을 선택하고 **4초 후 선택한 영수증 창 저장**을 누릅니다.
5. 프로그램 창이 숨겨지면 **4초 안에 선택한 영수증 창을 직접 클릭**해 맨 앞으로 가져옵니다.
6. 저장이 끝날 때까지 다른 창으로 전환하지 않습니다. 창이 닫혔거나 선택한 창이 맨 앞에 없으면 저장을 거부하고 다시 안내합니다.

스크롤 아래의 내용이나 다른 페이지는 화면 캡처에 포함되지 않습니다. 영수증 전체가 필요하면 공식 전체 출력에서 PDF로 저장한 뒤 가져오세요. 화면 밖으로 나간 창은 화면 안으로 옮기거나 최대화하고 다시 시도합니다.

PDF를 가져올 때는 열람 가능한 실제 영수증 PDF를 선택하세요. 암호 입력이 필요한 문서, 손상·빈 파일, 지나치게 큰 파일은 설명과 함께 거부됩니다. 변환 중 실패하면 해당 가져오기가 만든 파일만 정리하고 사용자가 선택한 원본은 변경하지 않습니다.

## 6. 결과 확인과 인쇄

저장 위치 아래에 `출장일_자차/기차_출장지_시각` 형태의 결과 폴더가 만들어집니다.

| 파일 | 내용 |
| --- | --- |
| `travel_report.html` | 이용 유형별 출장정보, 저장된 원본 이미지, 출처·저장 시각, 누락·실패 안내 |
| `car_settlement.html` | 자차 이용 전용 A4 증빙서. 경로·유가·통행료 원본을 항목별로 배치 |
| `rail_settlement.html` | 기차 이용 전용 A4 출장운임정산 증빙서. 원본 영수증을 최대 두 개씩 배치 |
| `*.png` | 원본 화면 캡처 또는 원본 PDF의 페이지 변환 이미지 |
| 가져온 `*.pdf` | 선택한 PDF의 바이트를 그대로 보존한 원본 사본 |
| `manifest.json` | 이용 유형, 입력 정보, 출처, 파일 목록, 원본 PNG·PDF의 SHA-256 등 메타데이터 |

해당 유형의 정산서만 만들어집니다. HTML을 브라우저에서 열고 **Ctrl+P → PDF로 저장**하면 제출용 PDF를 만들 수 있습니다. 원본 PDF와 이미지는 결과 폴더에 함께 보관하세요. HTML 내부에 이미지가 포함되어 있어도 **원본 PDF 링크는 별도 첨부파일이 있어야 열립니다**.

제출 전 출장기간·유종·구간·실제 영수증과 누락 여부를 확인하세요. 화면이나 영수증을 새로 그리거나 금액을 바꿔 첨부하지 않습니다. 코레일 PC 영수증과 코레일톡 모바일 영수증의 모양은 다를 수 있습니다. 숙박비 영수증 수집은 현재 범위에 포함되지 않습니다.

## 7. 로그인 정보와 개인정보

- **하이패스 비밀번호**: 사용자가 저장을 선택하면 Windows 자격 증명에 보관합니다. 평문 설정 JSON이나 보고서에 비밀번호 입력값을 기록하지 않습니다.
- **설정**: `%LOCALAPPDATA%\TripEvidenceCapture\settings.json`에 출장정보·하이패스 아이디 등 입력·선택값이 저장될 수 있습니다.
- **자차 자동화 브라우저**: 로그인 상태와 쿠키가 `%LOCALAPPDATA%\TripEvidenceCapture\profiles`에 보관될 수 있습니다.
- **기차·일반 브라우저**: 평소 브라우저의 로그인 상태를 사용합니다. 코레일 비밀번호를 프로그램에 입력·저장하는 기능은 없습니다.
- **저장 정보 삭제**: 해당 하이패스 Windows 자격 증명을 삭제합니다. 설정 파일이나 브라우저의 로그인 쿠키까지 삭제하는 버튼은 아닙니다. 로그인 상태를 해제하려면 사이트에서도 로그아웃하세요.
- **원본 증빙**: 화면에 보이는 이름·거래 내역 등도 이미지에 그대로 들어갈 수 있습니다. 결과는 선택한 로컬 폴더에 저장되므로, 공유·제출 전 내용을 직접 확인하세요.

개인 영수증, 보고서, 브라우저 프로필, 로그인 설정을 GitHub 이슈나 저장소에 올리지 마세요. 오류를 알릴 때는 버전·선택 유형·사용한 버튼·개인정보를 가린 오류 화면을 남기면 확인에 도움이 됩니다.

## 8. 문제 해결

| 상황 | 확인할 내용 |
| --- | --- |
| 코레일에서 보안·접근 차단 표시 | 일반 브라우저에서 공식 사이트에 직접 접속해 확인하세요. v1.3.1은 영수증 수집 방식을 바꾼 버전이며 계정 인증·접근 차단의 해결을 보장하지 않습니다. |
| 기차 모드에서 자동 조회용 창 목록이 보이지 않음 | 일반 브라우저의 영수증은 **영수증 PDF 가져오기** 또는 **일반 브라우저·출력창 저장**으로 추가하세요. |
| 영수증이 PDF·별도 앱에서 열림 | 여러 페이지는 PDF 파일로 가져오고, 현재 영역만 필요하면 출력 창 저장을 사용하세요. |
| 출력 창이 목록에 없음 | 창을 먼저 열고 **PDF 뷰어·별도 출력창 포함 → 창 목록 새로고침**을 확인하세요. |
| ‘맨 앞에 오지 않았습니다’ 또는 창 전환 오류 | 목록에서 다시 선택하고 저장 버튼을 누른 뒤, 4초 안에 해당 영수증 창을 직접 클릭하세요. |
| 네이버 장소나 오피넷 조건을 확인하지 못함 | 열린 사이트에서 장소·출장일·유종을 직접 확인해 조회한 뒤, 대상 창을 선택해 저장하세요. |
| Chrome/Edge 실행 실패 | 자차 자동 조회에서 선택한 브라우저의 설치 여부와 프로그램 중복 실행 여부를 확인하세요. 기차 모드는 Windows 기본 브라우저를 사용합니다. |
| 건너뛰기를 누르니 수집이 끝남 | 마지막 선택 항목을 건너뛰면 보고서를 정리하고 결과 확인 상태로 돌아옵니다. 프로그램 종료와 다릅니다. |
| 화면·페이지 수와 사이트 수가 다름 | PDF 한 파일도 페이지별 이미지 여러 개가 될 수 있습니다. 보고서의 자료 목록과 원본 PDF를 확인하세요. |
| 저장된 자료가 없거나 일부 누락됨 | 결과와 **작업 기록**을 확인하고 필요한 자료를 다시 수집하세요. 미선택 항목과 선택 후 누락 항목은 구분해 표시됩니다. |

자차의 **이 사이트 건너뛰기**는 다음 선택 항목으로 이동합니다. 마지막 항목에서는 **마지막 항목 건너뛰기**로 표시됩니다. 기차는 영수증 추가 후 **코레일 수집 완료**로 마칩니다. **중지**는 진행 중인 작업이 정리된 뒤 반영되며 이미 저장한 자료는 보관합니다. 창을 닫을 때도 정리가 끝날 때까지 기다려 주세요.

## 9. 소스 실행·빌드·테스트

이 절은 개발용입니다. 릴리스 EXE만 사용하는 경우에는 필요하지 않습니다.

### 소스 실행

Windows의 Python 3.12와 표준 `tkinter`를 준비하고 프로젝트 폴더에서 실행합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

`실행.cmd`는 `dist`의 최신 버전 EXE를 우선 실행하고, 실행 파일이 없으면 설치된 Python으로 소스를 실행합니다. **수정한 소스를 직접 확인하려면 `python main.py`를 사용하세요.**

의존성은 `requirements.txt`에 정의되어 있습니다. 자차 자동 조회는 설치된 Chrome/Edge를 사용하므로 `playwright install`로 전용 브라우저를 받을 필요가 없습니다. 기차 모드는 일반 기본 브라우저를 사용합니다.

### EXE 빌드

```powershell
python -m pip install -r requirements-dev.txt
.\build.ps1
```

빌드 결과는 `dist/출장증빙캡처_v1.3.1.exe`입니다. GitHub 릴리스에서는 `BTR-v1.3.1-windows-x64.exe`라는 다운로드 이름을 사용합니다. 빌드에는 PyInstaller 6.22.3을 사용하며 실행 파일·가져온 영수증·개인 설정은 소스 Git 이력에 포함하지 않습니다.

### 테스트와 검증 범위

```powershell
python -m unittest discover -s tests -q
```

전체 테스트에는 임시 Windows 자격 증명을 작성·읽기·삭제하는 `test_credentials.py` 통합 테스트가 포함됩니다.

최근 **소스 검증**에서는 해당 자격 증명 통합 모듈을 제외한 **앱 기능 테스트 125개가 통과**했습니다. 가상 PDF·이미지·모의 브라우저로 다음을 확인했습니다.

- 자차·기차 보고서 분리, 제목·필드·정산서 구분
- PDF 전체 페이지 첨부와 원본 PDF·이미지의 바이트·SHA-256 보존
- 자료 누락·실패·건너뛰기 처리
- 기차 모드의 자동화 브라우저 실행 없이 PDF·출력 창을 추가하고 수집 완료하는 흐름
- HTML 이스케이프와 인증정보가 포함된 출처 URL 정리

배포용으로 빌드한 **EXE에서도 가상자료 검증이 통과**했습니다. 기차 수집 검사에서는 자동화 브라우저 실행 0회, 빈 상태에서 완료 시 수집 대기 유지, PDF 3페이지 저장과 원본 보존을 확인했습니다. 모드 검사에서는 유형별 제목·정산서 분리와 원본 보존을 포함한 6개 항목을 확인했습니다.

릴리스 게시 도구의 모의 안전성 테스트 10개도 통과했습니다. `tools/publish_release.py`는 기본 실행 시 파일 해시만 확인하는 dry-run이며, 게시에는 명시적인 `--publish`와 대상 저장소·태그·커밋·파일 지정이 필요합니다. 기존 릴리스 파일과 충돌하면 교체하지 않고 중단합니다.

`tools/`에는 공개 화면 및 로컬 가상자료를 확인하는 추가 개발 도구가 있습니다. **이 검증은 실제 개인 계정의 로그인 성공, 추가 인증, 영수증 발급 권한이나 기관의 정산 승인까지 확인한 것은 아닙니다.**

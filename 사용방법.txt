출장 증빙 캡처 사용방법

1. 실행 준비
Windows PC에 Chrome 또는 Microsoft Edge가 설치되어 있어야 합니다.
ZIP을 모두 풀고 BTR.exe를 더블클릭하세요. 단일 파일을 받았다면 BTR-v1.4.1-windows-x64.exe를 실행하세요. 소스 폴더에서는 실행.cmd를 사용할 수 있습니다.
EXE는 Python이나 Playwright 전용 브라우저를 따로 설치할 필요가 없습니다.

2. 출장 방식 선택과 공통 정보
상단에서 ‘자차 이용’ 또는 ‘기차 이용’을 먼저 선택하세요. 작업 중에는 방식을 바꿀 수 없습니다.
- 자차 이용: 네이버 지도 경로, 오피넷 일일 유가, 하이패스 통행료 영수증을 수집합니다. 필요한 항목만 체크할 수 있습니다.
- 기차 이용: 평소 사용하는 일반 브라우저에서 코레일에 직접 로그인하고 영수증을 수집합니다. 지도·유가·하이패스 항목과 자격 입력은 표시하지 않습니다.
기본 정보에서 출장 시작일·종료일, 출발지와 출장지, 저장 위치를 확인하세요. 종료일을 비우면 당일 출장으로 처리합니다. 브라우저 선택은 자차 자동 조회에 적용되며, 기차 이용은 Windows 기본 브라우저를 엽니다.
공통 출장정보에서 소속·직급·성명·출장목적을 입력하세요. 두 방식 모두 보고서 표지에 사용합니다.
자차 이용은 출발지·도착지와 차량 유종을 확인하고, 기차 이용은 기차 전용 탭에서 왕복 역을 입력하세요.
자차는 ‘캡처 시작’, 기차는 ‘수집 시작’을 누르면 해당 방식의 자료 수집을 진행합니다. 다른 방식의 자료는 별도 실행으로 수집하세요.
자차 결과는 ‘자차 이용 출장보고서’와 car_settlement.html, 기차 결과는 ‘기차 이용 출장보고서’와 rail_settlement.html로 만들어집니다.
결과 폴더 이름에도 ‘자차’ 또는 ‘기차’가 표시됩니다. 교통비 금액을 임의로 산정하지 않으며 원본 증빙을 확인해 정산하세요.

3. 하이패스 로그인과 영수증
로그인 정보 저장은 선택 사항입니다. 저장하지 않아도 열린 브라우저에서 직접 로그인할 수 있습니다.
저장하려면 아이디와 비밀번호를 입력하고 ‘이 PC에 로그인 정보 저장’을 누르세요.
비밀번호는 Windows 자격 증명에 보관되며, 저장 후 프로그램의 입력칸은 비워집니다.
보안프로그램 확인, 보안 입력, 추가 인증은 하이패스 사이트의 정상 절차로 직접 진행하세요.
사용내역에서 출장일과 카드를 확인하고 필요한 영수증을 선택하세요.
영수증이 PDF로 열리거나 화면 저장이 되지 않으면, 하이패스의 공식 출력·인쇄 기능에서 PDF로 저장한 뒤 프로그램의 ‘영수증 PDF 가져오기’를 누르고 그 파일을 선택하세요.
가져온 PDF는 원본을 보관하고 모든 페이지를 PNG로 변환해 보고서에 넣습니다. 첫 페이지만 저장된 것은 아닌지, 영수증 전체 페이지가 맞는지 확인하세요.
프로그램이 연 브라우저에서 PDF를 다운로드하면 자동으로 가져옵니다. 자동으로 반영되지 않으면 ‘영수증 PDF 가져오기’에서 직접 선택하세요.
실제 계정의 로그인·추가 인증은 검증하지 않았으므로 사이트 상태에 따라 직접 로그인이 필요할 수 있습니다.
보안프로그램 때문에 자동화 브라우저에서 로그인하기 어렵다면, 하이패스 화면 준비 대기 단계에서 ‘일반 브라우저·출력창 저장’을 누르세요.
평소 사용하는 Chrome 또는 Edge에서 정상적으로 직접 로그인하고 영수증을 표시하세요. 필요한 경우 ‘일반 브라우저로 하이패스 열기’를 누르세요.
‘일반 브라우저·출력창 저장’ 창 안에서 ‘PDF 뷰어·별도 출력창 포함’이 체크되어 있는지 확인하세요. 기본으로 켜져 있으며, 영수증이 PDF 뷰어나 별도 출력 앱으로 열려도 창 목록에서 선택할 수 있습니다.
이 창의 목록을 새로고침하고 실제 영수증이 보이는 브라우저·PDF 뷰어·출력 앱 창을 선택한 뒤 ‘4초 후 선택한 영수증 창 저장’을 누르세요.
프로그램 창이 숨겨지면 4초 안에 해당 영수증·출력 창을 직접 클릭하세요. 선택한 창이 맨 앞에 있을 때만 저장됩니다.
이 모드는 보안프로그램을 우회하거나 인증을 자동 처리하지 않습니다.

4. 코레일 KTX 영수증과 출장운임정산 서식
상단에서 ‘기차 이용’을 선택하고 공통 출장정보와 ‘철도 구간 · 코레일’ 탭의 출발역·도착역을 입력하세요. 코레일은 기차 이용에 자동으로 포함됩니다.
가는 편과 오는 편 역이 다르면 귀환 출발역·귀환 도착역도 입력하세요. 예: 오송→서울 / 용산→오송. 귀환역을 비우면 가는 편의 역순을 사용합니다.
기본 정보 탭의 출장일은 시작일이며, 종료일을 비우면 당일 출장으로 처리합니다. 기본 정보의 출장지는 정산서 출장지에 들어갑니다.
기차 이용에서는 지도·유가·하이패스 자료가 조회되지 않습니다.
‘수집 시작’을 누르면 Windows 기본 브라우저로 코레일 공식 홈페이지 https://www.korail.com/ticket 를 엽니다. 평소 사용하는 브라우저의 로그인 환경에서 사이트가 제공하는 정상 로그인·추가 인증을 직접 진행하세요.
기차 이용은 별도의 Playwright 자동화 브라우저를 실행하지 않습니다. 코레일 마이페이지에서 공식 이용내역·영수증 메뉴를 직접 열어 해당 출장의 영수증을 준비하세요.
일반 브라우저에서도 보안·접근 차단이 계속되면 코레일의 공식 안내를 확인하세요. 프로그램이 코레일 인증을 대신하거나 접근 차단을 해제하지 않습니다.
조회 화면의 기간 기준이 구입일인지 승차일인지 확인하세요. 예매일과 출장일은 다를 수 있으며, 목록에서 해당 출장의 실제 승차일·출발역·도착역을 확인하고 영수증을 여세요.
영수증을 준비한 뒤 아래 방법으로 추가하세요.
- PDF: 코레일의 공식 출력·인쇄 기능에서 영수증을 PDF로 저장하고 ‘영수증 PDF 가져오기’에서 직접 선택하세요. 원본 PDF와 모든 페이지의 PNG를 보관합니다. 일반 브라우저에서 다운로드한 파일도 이 버튼으로 직접 추가하세요.
- 화면: ‘일반 브라우저·출력창 저장’을 열고 목록을 새로고침한 뒤 실제 영수증이 보이는 브라우저·PDF 뷰어·출력 앱 창을 선택하세요. ‘4초 후 선택한 영수증 창 저장’을 누르면 프로그램 창이 숨겨집니다. 4초 안에 선택한 영수증 창을 직접 클릭하세요.
화면 저장은 현재 보이는 영역만 포함합니다. 길거나 여러 페이지인 영수증 전체를 보관하려면 PDF로 가져오세요. 로그인 화면이나 조회 목록 대신 실제 영수증을 선택하세요.
한 장을 저장해도 수집이 끝나지 않습니다. 왕복 등 필요한 영수증을 계속 추가한 뒤 반드시 ‘코레일 수집 완료’를 누르세요. 중지 시 이미 저장된 자료는 보관합니다.
결과의 travel_report.html에서 ‘출장운임정산 증빙영수증 열기’를 누르거나 rail_settlement.html을 직접 여세요. 원본 영수증을 한 쪽에 최대 두 장씩 배치하며 Ctrl+P → PDF로 저장할 수 있습니다.
‘사용자 입력’으로 표시된 표 정보는 영수증에서 자동으로 확인된 사실이 아닙니다. PDF·외부창 캡처의 실제 승차일·역·금액은 원본과 대조하세요.
코레일 홈페이지 PC 영수증과 코레일톡 모바일 영수증의 모양은 다를 수 있습니다. 공식 원본을 보관하며 모바일 모양으로 영수증을 새로 그리지 않습니다.
코레일 계정 비밀번호는 프로그램에 입력하거나 저장하지 않습니다. 로그인 상태와 쿠키는 평소 사용하는 브라우저에서 관리합니다.
실제 계정의 로그인·이용내역·추가 인증과 발급 권한은 검증하지 않았습니다. 저장 기능은 개발용 가상자료로 검증했습니다.
숙박비 영수증 수집은 이번 버전에 포함하지 않습니다.

5. 브라우저 버튼 매크로 · v1.4.1
버튼 좌표는 처음 한 번 직접 등록해야 합니다. 이 기능은 DOM이나 화면 인식으로 버튼을 자동 탐색하지 않으며, 로그인·추가 인증은 사용자가 먼저 직접 완료합니다.
BTR의 ‘브라우저 버튼 매크로’를 열고 ‘창 새로고침’을 누른 뒤 ‘이미 열려 있는 브라우저 창 · 직접 선택’에서 대상 창을 선택하세요. 기존 Chrome·Edge·Internet Explorer 브라우저 창이 대상이며 현재 안내의 사용 환경은 Edge입니다.
매크로 창이 열려 있는 동안 BTR 본창의 수집 버튼은 잠깁니다. 끝나면 매크로 창을 닫고 PDF·출력창 수집을 계속하세요.

창 크기 자동 맞춤
새 매크로는 ‘기록·실행 전에 선택한 창 자동 최대화’가 기본 체크입니다. 기록·실행 버튼을 누르면 4초 카운트다운 전에 선택한 창을 복원·최대화하고 맨 앞으로 가져오기를 시도합니다. Windows 제한으로 전면 전환이 되지 않으면 4초 안에 해당 창을 직접 맨 앞으로 가져오세요.
체크를 해제한 새 매크로는 현재 창 크기에서 첫 좌표를 등록합니다. 이후 실행 전에는 기록한 브라우저 내용 영역의 정확한 가로·세로 크기로 창을 자동 맞춥니다. 좌표 비율을 바꾸어 실행하지 않습니다.
첫 단계가 있으면 창 모드가 고정됩니다. 단계 이름·대기·순서를 편집해도 모드는 유지되며, 바꾸려면 ‘새 매크로’에서 다시 등록하세요.
Windows 전체 해상도·배율, 브라우저 확대율·스크롤·페이지 배치는 변경하지 않습니다. 다른 DPI, 맞출 수 없는 화면 작업영역, 기록과 다른 최대화 내용 영역 크기는 클릭 전에 중지합니다.

위치 등록
1) 첫 번째 버튼이 있는 화면을 준비하고 ‘단계 이름’과 ‘클릭 후 대기(초)’를 입력하세요. 대기는 0.2~30초입니다.
2) ‘4초 후 포인터 위치 등록’을 누르세요. 창을 준비한 뒤 카운트다운이 시작되면 포인터를 버튼 위에 올려두세요. 등록을 위해 버튼을 직접 클릭할 필요는 없습니다. 자동 전면 전환이 안 됐다면 제목 표시줄 등으로 대상 창을 먼저 맨 앞으로 가져오세요.
3) 다음 단계가 다른 화면에 있으면 사용자가 그 화면을 직접 준비한 뒤 같은 방법으로 위치를 등록하세요. 등록만으로 조회나 페이지 이동이 실행되지는 않습니다.
4) ‘이름·대기 수정’, ‘삭제’, ‘위로’, ‘아래로’로 단계와 순서를 정리할 수 있습니다.

순서대로 실행
1) 브라우저를 첫 단계 화면으로 돌리고 확대율·페이지 배치·스크롤 위치를 등록 때와 같게 준비하세요.
2) ‘4초 후 실행’을 누르면 카운트다운 전에 최대화 또는 기록한 내용 영역 크기로 자동 맞춤을 시도합니다. 자동으로 앞에 오지 않았다면 4초 안에 선택한 창을 직접 클릭하세요. 실패 안내가 나오면 대상 창을 직접 활성화하고 다시 시도하세요.
3) 단계마다 왼쪽 클릭을 한 번 보내고 지정 시간만큼 기다립니다. 실행 중에는 결과를 지켜보며 다른 창으로 전환하거나 크기·배율을 바꾸지 마세요.
4) 완료 후 매크로 창을 ‘닫기’로 닫고 ‘영수증 PDF 가져오기’ 또는 ‘일반 브라우저·출력창 저장’으로 실제 영수증을 추가하세요.

긴급 중지
Esc, 매크로 창의 ‘중지’, 또는 포인터를 주 모니터의 맨 왼쪽 위 모서리로 옮겨 중지할 수 있습니다.
카운트다운 전 창 자동 맞춤은 준비 단계입니다. 각 클릭 직전에 대상 창·포커스·내용 영역 크기·DPI를 확인하고, 창이 닫혔거나 기록한 조건과 다르면 중단합니다. 단계별 대기 중에도 Esc·중지 요청·포인터의 왼쪽 위 이동은 확인합니다. 일시정지는 없으며 다시 실행할 때는 첫 단계 화면을 준비하세요.

JSON과 확인 사항
‘JSON 내보내기’는 단계 이름·클릭 좌표·대기시간을 저장하며 프로필 v2의 window_mode에 창 모드를 보관합니다. ‘JSON 가져오기’는 기존 v1 JSON도 지원하며 v1은 기록 크기 모드로 불러와 실행 전에 기록한 내용 영역 가로·세로 크기로 자동 맞춥니다. 좌표를 비율로 바꾸지 않습니다.
가져오기만으로 실행되지 않습니다. 대상 창을 직접 선택하고 ‘4초 후 실행’을 눌러야 합니다. 단계가 있으면 창 모드는 고정되며 다른 모드는 ‘새 매크로’에서 다시 등록하세요.
브라우저의 로그인 입력내용·URL·창 제목·PID를 자동 수집해 저장하지 않습니다. 단계 이름에도 비밀번호·개인 식별정보를 적지 마세요.
이 기능은 클릭만 전달하며 조회·영수증 발급의 성공 여부를 확인하지 않습니다. 로딩 지연·팝업·스크롤·확대율 변화로 버튼 위치가 달라지면 중지하고 위치·대기시간을 다시 확인하세요.
IE 모드를 강제로 켜지 않으며 실제 사이트의 Internet Explorer 지원이나 로그인·접근 차단 해결은 검증하지 않았습니다.

6. 직접 화면 저장
자차 이용 중 프로그램이 연 브라우저에서 화면 준비 안내가 표시되면 원하는 조회 결과를 준비하세요.
영수증·인쇄 화면 등 새 창을 열었다면 ‘창 목록 새로고침’을 누르세요. 하이패스 조회 창에서 연결된 별도 출력 창도 이 목록에서 확인할 수 있습니다. 출력 창의 주소가 비어 있거나 달라도 실제 영수증이 보이는지 직접 확인하세요.
자차의 ‘저장할 창’ 목록에서 대상 창을 선택한 뒤 ‘현재 화면 저장’을 누르세요. 현재 보고 있는 사이트와 선택한 창이 일치하는지 확인하세요.
기차 이용의 영수증과 외부 브라우저·PDF 뷰어·출력 앱 창은 ‘일반 브라우저·출력창 저장’을 이용하세요. 그 창 안의 ‘PDF 뷰어·별도 출력창 포함’ 옵션을 확인한 뒤 창 목록을 새로고침하고 선택하세요. PDF 전체 페이지가 필요하면 ‘영수증 PDF 가져오기’를 이용하세요.
‘일반 브라우저·출력창 저장’은 PC 화면에 보이는 해당 창 전체를 저장합니다. 브라우저인 경우 주소 표시줄도 포함됩니다. 가려지거나 화면 밖으로 나간 부분, 스크롤 아래의 내용은 저장하지 않습니다.
긴 영수증이나 여러 페이지짜리 영수증은 공식 전체 출력 기능에서 PDF로 저장한 뒤 ‘영수증 PDF 가져오기’를 이용하세요. 일반 브라우저 창 저장은 현재 보이는 영역만 저장하므로 PDF 전체 페이지를 보관하는 방법과 다릅니다.
자차 이용에서 불필요한 사이트는 ‘이 사이트 건너뛰기’로 넘길 수 있습니다. 진행 상태 제목에 현재 순서와 다음 항목이 표시됩니다. 네이버·오피넷처럼 자동 저장된 항목은 빠르게 지나갈 수 있습니다. 마지막 선택 항목에서는 ‘마지막 항목 건너뛰기’로 표시되며, 이를 누르면 보고서를 정리하고 대기 상태로 돌아옵니다. 프로그램 자체가 종료되는 것은 아닙니다.
기차 이용은 영수증을 추가한 뒤에도 수집 대기를 유지합니다. 필요한 영수증을 모두 추가하고 ‘코레일 수집 완료’를 누르세요. ‘중지’는 진행 중인 작업이 정리된 뒤 반영됩니다.

7. 결과 확인과 PDF 저장
선택한 저장 위치 아래에 출장별 결과 폴더가 만들어집니다.
- 사이트별 원본 PNG: 자동화 브라우저의 페이지 캡처는 실제 웹페이지 내용만 저장하며 주소 표시줄과 브라우저 테두리는 포함하지 않습니다. ‘일반 브라우저·출력창 저장’은 선택한 창의 현재 보이는 영역을 저장하며 브라우저인 경우 주소 표시줄도 포함됩니다.
- 가져온 영수증 PDF 원본과 페이지별 PNG: PDF를 가져오면 파일 원본과 모든 페이지의 이미지를 보관합니다. 보고서에서 페이지 수와 내용을 확인하고, 제출할 때는 원본 PDF도 함께 보관하세요.
- car_settlement.html: 자차 이용 전용 증빙서식입니다. 경로·유가·통행료 원본을 항목별로 배치합니다.
- rail_settlement.html: 기차 이용 전용 출장운임정산 서식입니다. 소속·성명 등 입력 정보와 원본 영수증을 배치합니다.
- travel_report.html: 원본 화면, 출장 정보, 출처 URL, 캡처 시각을 포함한 보고서입니다.
- manifest.json: 캡처 메타데이터와 원본 이미지·가져온 PDF의 SHA-256을 기록한 파일입니다.
‘보고서 열기’ 또는 ‘결과 폴더 열기’로 확인하세요.
HTML 보고서를 브라우저에서 열고 Ctrl+P를 눌러 ‘PDF로 저장’을 선택하면 PDF를 만들 수 있습니다.
자동 저장된 화면도 날짜·유종·출발지·도착지와 영수증 내용을 확인한 뒤 제출하세요.
PDF를 가져올 때는 실제 영수증 PDF를 선택하세요. 비밀번호가 설정되었거나 손상된 파일은 읽지 못할 수 있으며, 파일을 확인한 뒤 다시 가져올 수 있습니다.
캡처가 없거나 일부 누락되면 보고서의 건너뛰기·실패 및 확인 사항을 확인하세요.

8. 날짜와 로그인 상태
출장일과 실제 조회·캡처 시점은 다를 수 있습니다. 지도는 조회 시점의 참고 경로이며 과거의 실제 운행을 보장하지 않습니다.
자차 자동화 브라우저의 로그인 상태와 쿠키는 %LOCALAPPDATA%\TripEvidenceCapture\profiles에 보관됩니다. 기차 이용과 일반 브라우저 창 저장은 평소 브라우저의 로그인 상태를 사용합니다.
‘저장 정보 삭제’는 Windows 자격 증명의 비밀번호만 삭제하며, 브라우저의 로그인 쿠키는 삭제하지 않습니다.
로그인 상태도 해제하려면 해당 사이트에서 로그아웃하세요.
프로그램을 닫으면 브라우저 정리를 기다린 뒤 종료됩니다.

개발 환경에서 실행·빌드
Python 3.12(표준 tkinter 포함)를 설치하고 아래 명령을 소스 폴더에서 실행하세요.
  python -m pip install -r requirements-dev.txt
  python main.py
EXE 빌드는 PowerShell에서 .\build.ps1을 실행하세요.
build.ps1은 trip_capture.__version__에서 버전을 읽습니다. v1.4.1 완성 파일은 dist\출장증빙캡처_v1.4.1.exe입니다. 빌드에는 PyInstaller 6.22.3을 사용합니다.
자차 자동 조회의 Playwright는 설치된 Chrome/Edge를 사용하므로 playwright install 명령은 필요하지 않습니다. 기차 이용은 Windows 기본 브라우저를 사용합니다.

BTR v1.4.1 - Edge 자동 창 맞춤·버튼 클릭 테스트

1. ZIP을 모두 풀고 BTR.exe를 실행하세요. Python 설치는 필요하지 않습니다.
2. Microsoft Edge에서 samples/macro-practice.html 파일을 여세요.
   개발용 연습 화면이며 인터넷·로그인·실제 영수증·결제를 사용하지 않습니다.
3. BTR 오른쪽 위의 '브라우저 버튼 매크로'를 누릅니다.
4. '창 새로고침'을 누르고 연습 화면을 연 Edge 창을 직접 선택하세요.
5. '기록·실행 전에 선택한 창 자동 최대화'를 켠 상태로 둡니다. 새 매크로의 기본값입니다.
6. 단계 이름 '조회 연습', 클릭 후 대기 1초를 입력하고 '4초 후 포인터 위치 등록'을 누릅니다.
7. 선택한 Edge 창이 자동 최대화된 뒤 4초 안에 '1. 조회 연습' 버튼 위에 포인터를 두세요.
   창이 앞으로 오지 않았다면 빈 곳을 클릭해 먼저 선택하세요. 위치 등록 자체는 버튼을 클릭하지 않습니다.
8. 같은 방법으로 '2. 영수증 연습', '3. 확인 연습' 위치를 추가합니다. 좌표 등록은 처음 한 번 필요합니다.
9. Edge 연습 페이지를 새로고침해 카운터를 0으로 만드세요. 브라우저 확대율·스크롤은 등록 때와 유지합니다.
10. 매크로 창에서 '4초 후 실행'을 누릅니다. Edge가 자동 최대화되고 창 크기가 안정된 뒤 카운트다운합니다.
    앞으로 오지 않았다면 4초 안에 Edge 창을 선택하세요. 버튼 세 개의 카운터가 1 / 1 / 1이 되는지 확인하세요.

다음 실행에도 선택한 Edge 창을 자동으로 맞춥니다. 창을 손으로 매번 확대할 필요가 없습니다.
자동 최대화를 해제한 새 매크로는 첫 위치 등록 때의 내용 영역 크기로 재생 전에 자동 맞춥니다.
기존 v1 JSON은 기록 크기 모드로 불러오며 v2 JSON에는 창 모드를 보관합니다.
위치가 등록된 후에는 창 모드가 잠깁니다. 모드를 바꾸려면 '새 매크로'로 다시 등록하세요.
다른 DPI·작업영역 등으로 기록한 크기를 맞출 수 없으면 좌표를 스케일하지 않고 클릭 전에 멈춥니다.
Windows 전체 해상도·화면 배율과 브라우저 확대율·스크롤은 변경하지 않습니다.

Esc, 주 모니터 왼쪽 위 모서리로 포인터 이동, 매크로 창의 중지로 실행을 멈출 수 있습니다.
각 클릭 직전에 대상 창의 프로세스·크기·DPI·전면 상태와 해당 지점을 가리는 창을 확인하고 다르면 중단합니다.
매크로는 등록된 위치로 마우스 클릭만 보내며 버튼 인식·조회 성공·영수증 발급 성공을 자동 판정하지 않습니다.
실제 사이트에서는 로그인·보안 인증을 직접 완료한 뒤 조회·출력 버튼의 위치를 등록하세요.
새 팝업·별도 출력 앱은 해당 창을 다시 선택하거나 BTR의 출력 창 저장 기능을 사용하세요.
매크로 관리 창을 닫으면 BTR의 PDF·출력 창 수집 버튼을 다시 사용할 수 있습니다.
JSON 내보내기로 좌표·단계 이름·대기시간·창 모드를 보관할 수 있습니다. 로그인 정보는 자동 기록하지 않습니다.

기존 PDF 수집 시험:
기차 이용 → 테스트용 과거 날짜·출장지 입력 → 수집 시작 → 영수증 PDF 가져오기 →
samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf 선택 → 3페이지 확인 → 코레일 수집 완료 → 보고서 열기.
이 PDF는 모든 페이지에 SYNTHETIC DEVELOPMENT DATA가 표시된 개발용 가상자료로 실제 지출 증빙이 아닙니다.

검증: 자격증명 통합 모듈 1개 제외 소스 테스트 189개, EXE 자체검사 3종 통과.
매크로 자체검사는 가짜 어댑터·시계로 검사합니다. 실제 Edge 창 조절·클릭·개인 계정 로그인은 검증하지 않았습니다.
이 실행파일에는 디지털 서명이 없습니다. 실행 제한은 해당 PC 담당자에게 확인하세요.

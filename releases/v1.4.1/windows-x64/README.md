# BTR v1.4.1 · Edge 자동 창 맞춤

**[BTR.exe 다운로드](https://github.com/xoghlda/BTR/raw/refs/heads/main/releases/v1.4.1/windows-x64/BTR.exe)** · [ZIP 패키지](https://github.com/xoghlda/BTR/releases/download/v1.4.1/BTR-v1.4.1-windows-x64.zip)

Windows 64비트용 실행파일입니다. Python 설치 없이 실행합니다. 버튼 위치를 등록하거나 재생하기 전에 선택한 Edge 창을 자동으로 맞추므로, 매번 창 크기를 손으로 조절할 필요가 없습니다.

## 창 크기를 자동으로 맞추는 방법

1. BTR의 **브라우저 버튼 매크로**에서 대상 Edge 창을 직접 선택합니다.
2. 새 매크로의 **기록·실행 전에 선택한 창 자동 최대화**를 켠 상태로 버튼 위치를 등록합니다. 창을 최대화하고 안정된 뒤 4초 카운트다운합니다. 그동안 대상 버튼 위에 포인터를 두세요.
3. **4초 후 실행**을 누르면 같은 창을 다시 최대화한 뒤 등록 순서대로 클릭합니다. 창이 앞으로 오지 않았다면 카운트다운 동안 대상 창을 직접 선택하세요.

처음 한 번 버튼 위치를 등록해야 합니다. 자동 최대화를 해제하면 첫 등록 당시의 내용 영역 크기를 보관하고 재생 전에 복구합니다. 기존 v1 JSON도 기록 크기 모드로 불러오며, 새 v2 JSON에는 창 모드가 저장됩니다. 위치가 등록된 뒤 창 모드를 바꾸려면 **새 매크로**를 사용하세요.

브라우저 확대율·스크롤·페이지 배치는 등록 때와 같아야 합니다. Windows 전체 해상도·화면 배율은 변경하지 않습니다. 다른 DPI나 작업영역 등으로 크기를 맞출 수 없으면 좌표를 스케일하지 않고 클릭 전에 중지합니다.

## Edge에서 먼저 연습하기

1. ZIP을 모두 풀고 `BTR.exe`를 실행합니다.
2. Edge에서 `samples/macro-practice.html`을 엽니다. 로그인·인터넷 연결 없이 시험하는 개발용 페이지입니다.
3. 매크로에서 해당 Edge 창을 선택하고 자동 최대화를 켠 뒤 세 버튼 위치를 각각 등록합니다. 위치 등록 자체는 버튼을 누르지 않습니다.
4. 연습 페이지를 새로고침해 카운터를 0으로 만들고 매크로를 실행합니다.
5. 각 버튼 횟수가 1씩 증가하는지 확인합니다. **Esc**, 주 모니터 왼쪽 위로 포인터 이동, **중지**로 멈출 수 있습니다.

실제 사이트에서는 로그인·인증을 먼저 직접 완료하세요. 매크로는 좌표 클릭만 전달하며 버튼을 자동 인식하거나 조회·영수증 발급 성공을 판정하지 않습니다. 새 팝업·출력 앱은 대상 창을 다시 선택해야 합니다. 매크로 창을 닫은 뒤 BTR의 PDF 가져오기·출력 창 저장으로 자료를 모으세요.

## 포함 파일과 검증

- `BTR.exe`: v1.4.1 실행파일
- `사용방법.txt`, `빠른테스트.txt`: 한글 안내
- `samples/macro-practice.html`: 버튼 3개의 클릭 횟수를 확인하는 연습 화면
- `samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf`: 기존 PDF 수집용 개발 예제
- `BUILDINFO.json`: 소스 커밋·빌드·검증 범위
- `SHA256SUMS-in-package.txt`: 배포 파일 6개의 검증값

Windows 자격 증명 통합 모듈 1개를 제외한 소스 테스트 189개와 EXE 자체 검사 3종(매크로·PDF 수집·자차와 기차 서식)이 통과했습니다. 매크로 검사의 13개 항목은 가짜 어댑터·시계로 확인했으며 실제 Edge 창 조절·클릭이나 개인 계정 로그인을 검증한 결과는 아닙니다. 실행파일에는 코드 서명이 없습니다.

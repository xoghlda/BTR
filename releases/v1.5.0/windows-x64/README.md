# BTR v1.5.0 · 로그인부터 전체 흐름

**[BTR.exe 다운로드](https://github.com/xoghlda/BTR/raw/refs/heads/main/releases/v1.5.0/windows-x64/BTR.exe)** · [ZIP 패키지](https://github.com/xoghlda/BTR/releases/download/v1.5.0/BTR-v1.5.0-windows-x64.zip)

Windows 64비트용입니다. ZIP을 모두 풀고 BTR.exe를 실행하면 Python 설치 없이 사용할 수 있습니다.

## 사용 순서

1. 메인에서 출장 유형·기간·구간·저장 폴더와 사이트를 지정하고 **로그인부터 전체 자동화**를 누릅니다.
2. 일반 Edge 창을 선택하고 **전체흐름예시 · 미검증 틀**을 불러오거나 단계를 직접 추가합니다.
3. 로그인 칸·조회 조건 칸·버튼 위치를 실제 화면에서 처음 한 번 등록합니다. 창을 자동으로 맞춘 뒤 4초 안에 포인터를 해당 위치에 두세요. 미등록 좌표가 있으면 실행하지 않습니다.
4. **사이트별 계정**에 아이디·비밀번호를 입력합니다. 저장은 선택 사항이며 Windows 자격 증명 관리자를 사용합니다. 계정은 흐름 JSON에 넣지 않습니다.
5. URL 이동→아이디/비밀번호→로그인 클릭→필요시 인증 대기→출장 변수 입력→조회→영수증 열기→화면 저장 또는 PDF 수집 순서로 편집합니다.
6. 새 브라우저 영수증 창이면 새 창 전환 단계를 넣습니다. PDF는 자료 탭에 이번 실행의 정확한 저장 파일 경로를 지정합니다. 변경 없는 과거 PDF는 자동 수집하지 않습니다.
7. 실행 후 자동화 창을 닫고 메인의 **보고서 열기**에서 원본·출장일·구간·금액과 누락 여부를 확인합니다. 오류·중지 시에도 이미 모은 자료를 보존합니다.

추가 인증·보안문자·보안 입력은 직접 완료한 뒤 계속합니다. 로그인 실패를 자동 반복하지 않습니다. Ctrl+P는 인쇄 화면을 열기만 하므로 프린터·저장 대화상자의 설정은 확인해야 합니다. 페이지 확대율·스크롤·화면 배치를 등록 때와 유지하세요.

## 계정 없이 연습

Edge에서 `samples/workflow-practice.html`을 엽니다. 실제 계정이나 URL 이동 단계는 사용하지 않습니다. 일반 입력으로 개발용 날짜·출발·도착 칸을 채우고 조회·새 영수증 창 열기의 클릭 위치를 등록한 뒤 **새 창 전환→화면 증빙 저장**을 추가하세요. 개발용 새 창이 보고서에 들어가는지 확인할 수 있습니다.

기존 클릭 연습은 `samples/macro-practice.html`, PDF 수집 연습은 `samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf`를 사용합니다. 모두 실제 증빙이 아닌 개발 자료입니다.

## 구성과 검증

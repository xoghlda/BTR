BTR v1.5.0 - 로그인부터 전체 흐름

ZIP을 모두 풀고 BTR.exe를 실행하세요. Python 설치는 필요하지 않습니다.

실제 사이트의 전체 흐름을 처음 한 번 등록하기:
1. 메인 창에서 자차/기차 유형, 출장일·구간·저장 폴더와 필요한 사이트를 지정합니다.
2. '로그인부터 전체 자동화'를 누르고 일반 Microsoft Edge 창을 선택합니다.
3. 전체흐름예시를 불러오세요. 예시는 편집용 틀이며 입력·클릭 위치는 미등록입니다.
4. 로그인 칸·조회 조건 칸·버튼이 보이는 각 실제 화면에서 해당 단계를 선택하고 위치를 등록합니다.
   선택한 Edge 창을 자동 최대화한 뒤 4초 안에 포인터를 해당 칸/버튼 위에 두세요. 등록 자체는 클릭하지 않습니다.
5. 사이트별 계정 탭에 아이디·비밀번호를 입력합니다. 저장은 선택이며 이 PC의 Windows 자격 증명을 사용합니다.
   계정은 흐름 JSON에 넣지 않습니다. 저장 계정을 자동 조회하지 않으므로 필요하면 불러오기 버튼을 누르세요.
6. 날짜·구간의 일반 입력 값에는 메인 창의 {trip_date}, {trip_end_date}, {trip_date_compact},
   {trip_end_date_compact}, {origin}, {destination}, {rail_origin}, {rail_destination}를 사용할 수 있습니다.
7. 별도 영수증 창이면 출력 클릭 다음에 '새 창 전환→화면 증빙 저장'을 넣습니다.
   같은 창의 새 탭은 해당 탭 선택 동작을 등록합니다. 외부 출력 앱은 PDF 저장 후 PDF 증빙 저장을 사용하세요.
8. PDF는 자료 탭에서 정확한 저장 경로를 지정합니다. 실행 중 새로 저장되거나 바뀐 PDF만 가져옵니다.
   Ctrl+P는 인쇄 화면을 열기만 하므로 프린터·저장 대화상자의 설정은 확인해야 합니다.
9. 흐름 JSON을 내보내 다음 출장에 재사용합니다. 미등록 위치·누락 계정이 있으면 실행하지 않습니다.
10. 실행 중 추가 인증이 필요하면 인증 대기에서 직접 완료 후 '인증 완료·계속'을 누릅니다.
    추가 인증이 필요 없는 환경이면 해당 대기 단계를 제거할 수 있습니다. 로그인 실패를 자동 반복하지 않습니다.
11. 화면·PDF 수집 후 보고서를 자동 작성합니다. 자동화 창을 닫고 메인의 '보고서 열기'를 누르세요.
    오류·중지 시에도 이미 모은 원본과 누락 안내를 남깁니다. 출장일·구간·금액은 원본과 대조하세요.

계정 없이 먼저 연습하기:
Edge에서 samples/workflow-practice.html을 엽니다. URL 이동·아이디/비밀번호 단계는 넣지 마세요.
빈 흐름에 '일반·변수 입력'으로 개발용 날짜·출발·도착의 3개 위치를 등록하고,
'버튼 클릭'으로 조회와 새 영수증 창 열기를 등록한 뒤 '새 창 전환→화면 증빙 저장'을 추가합니다.
실행하면 개발용 새 영수증 화면을 저장해 보고서에 넣을 수 있습니다. 실제 계정을 입력하지 마세요.
기존 클릭 연습은 samples/macro-practice.html로 확인합니다.
기존 PDF 수집은 samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf로 확인합니다.
이 페이지와 PDF는 SYNTHETIC DEVELOPMENT DATA로 표시한 개발 자료이며 실제 지출 증빙이 아닙니다.

중지: Esc / 주 모니터 왼쪽 위로 포인터 이동 / 중지 버튼.
페이지 확대율·스크롤·화면 배치는 등록 때와 유지해야 합니다.
보안 입력이 수용되는지, 로그인·영수증 조회가 성공했는지는 실제 사이트에서 확인해야 합니다.
실제 개인 계정·브라우저 조작은 이번 자동 검증에서 수행하지 않았습니다. 코드 서명은 없습니다.

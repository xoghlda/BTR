BTR v1.4.0 - Edge 버튼 자동 클릭 테스트

1. ZIP을 모두 풀고 BTR.exe를 실행하세요. Python 설치는 필요하지 않습니다.
2. Microsoft Edge에서 samples/macro-practice.html 파일을 여세요.
   개발용 연습 화면입니다. 로그인·인터넷·실제 영수증·결제는 사용하지 않습니다.
3. BTR 오른쪽 위의 '브라우저 버튼 매크로'를 누릅니다.
4. '창 새로고침'을 누르고 연습 화면을 연 Edge 창을 직접 선택하세요.
5. 단계 이름 '조회 연습', 클릭 후 대기 1초를 입력하고 '4초 후 포인터 위치 등록'을 누릅니다.
6. 4초 안에 Edge 창의 빈 영역을 클릭해 맨 앞으로 가져오고 '1. 조회 연습' 버튼 위에 포인터를 올려 두세요.
   위치 등록은 버튼을 실제로 클릭하지 않습니다.
7. 같은 방법으로 '2. 영수증 연습', '3. 확인 연습' 위치를 추가하세요.
8. Edge 연습 페이지를 새로고침해 세 카운터를 0으로 만듭니다. 창 크기·화면 배율·확대율·스크롤을 유지하세요.
9. 매크로 창에서 '4초 후 실행'을 누르고, 4초 안에 선택한 Edge 창의 빈 곳을 클릭해 앞으로 가져옵니다.
10. 각 버튼이 한 번씩 클릭되어 카운터가 1 / 1 / 1이 되는지 직접 확인하세요.

Esc, 주 모니터 왼쪽 위 모서리로 포인터 이동, 매크로 창의 중지로 실행을 멈출 수 있습니다.
선택 창의 프로세스·크기·DPI·전면 상태가 달라지거나 다른 창이 지점을 가리면 다음 클릭을 중단합니다.
매크로는 등록된 위치로 마우스 클릭만 보내며 조회·영수증 발급 성공을 자동 판정하지 않습니다.
실제 사이트에서는 로그인·보안 인증을 직접 완료한 뒤 조회·출력 버튼의 위치를 등록하세요.
새 팝업·별도 출력 앱은 해당 창을 다시 선택하거나 BTR의 출력 창 저장 기능을 사용하세요.
매크로 관리 창을 닫으면 BTR의 PDF·출력 창 수집 버튼을 다시 사용할 수 있습니다.
JSON 내보내기로 좌표·단계 이름·대기시간을 보관할 수 있습니다. 로그인 정보는 자동 기록하지 않습니다.

기존 PDF 수집 시험:
기차 이용 → 테스트용 과거 날짜·출장지 입력 → 수집 시작 → 영수증 PDF 가져오기 →
samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf 선택 → 3페이지 확인 → 코레일 수집 완료 → 보고서 열기.
이 PDF는 모든 페이지에 SYNTHETIC DEVELOPMENT DATA가 표시된 개발용 가상자료로 실제 지출 증빙이 아닙니다.

이 실행파일에는 디지털 서명이 없습니다. 실행 제한은 해당 PC 담당자에게 확인하세요.

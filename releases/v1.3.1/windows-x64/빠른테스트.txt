BTR v1.3.1 - Windows 64비트 테스트 안내

1. ZIP 압축을 전부 풀고 BTR.exe를 실행하세요. Python 설치는 필요하지 않습니다.
2. 상단에서 '기차 이용'을 선택하세요.
3. 출장 시작일 2026-10-20, 종료일 2026-10-21, 출장지 '개발용 출장지' 등 테스트 정보를 입력하세요.
   공통 출장정보의 성명은 '테스트 사용자'로 입력하세요.
   철도 구간은 가는 편 오송 → 서울, 귀환 용산 → 오송 등으로 입력할 수 있습니다.
4. '수집 시작'을 누르세요. 기본 브라우저가 코레일 홈페이지를 엽니다.
   이 예제 PDF 시험에는 코레일 로그인이나 실제 승차권이 필요하지 않습니다.
5. 프로그램의 '영수증 PDF 가져오기'를 누르고 아래 파일을 선택하세요.
   samples/DEVELOPMENT_ONLY_SYNTHETIC_3PAGES.pdf
6. 3개 페이지 저장 안내를 확인한 뒤 '코레일 수집 완료'를 누르세요.
7. '보고서 열기' 또는 '결과 폴더 열기'로 PDF 원본, PNG 3개와 기차 정산 서식을 확인하세요.
   보고서의 정산 서식을 연 뒤 브라우저 인쇄 기능에서 PDF로 저장할 수 있습니다.

예제는 모든 페이지에 SYNTHETIC DEVELOPMENT DATA라고 표시한 개발용 가상 자료입니다.
실제 영수증이나 지출 증빙으로 사용하지 마세요.

실제 출장 시험은 사용방법.txt의 자차·기차 수집 순서를 참고하세요.
코레일 로그인과 추가 인증은 평소 브라우저에서 직접 진행합니다.
현재 PC 화면만 저장하려면 '일반 브라우저·출력창 저장', PDF 전체 페이지를 보관하려면 '영수증 PDF 가져오기'를 사용하세요.
이 테스트 빌드에는 디지털 서명이 없습니다. PC 정책으로 실행이 차단되면 해당 PC 관리자에게 문의하거나 저장소의 소스 실행 안내를 확인하세요.
